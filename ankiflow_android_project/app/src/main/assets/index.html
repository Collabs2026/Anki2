📲 安装到真机 (iOS / Android)

🍎 iPhone / iPad (iOS 全屏安装)

1. 将此单文件保存或在手机 Safari 打开；
2. 点击底部中间的「分享」图标 ⬆️；
3. 选择「添加到主屏幕 (Add to Home Screen)」，即可像原生 App 一样离线全屏运行。

🤖 Android 手机安装

1. 使用 Chrome / Edge 打开本页面；
2. 点击右上角菜单 ⋮ 选择「添加到主屏幕 / 安装应用」；
3. 或使用 Capacitor / Cordova 一键打包为 `.apk` 安装包。
